# Three.js Night Lab redesign

This branch rebuilds the portfolio around a single explorable 3D environment rather than a conventional scrolling card layout. The procedural scene is original and inspired by cyberpunk night-market/workshop spatial portfolios: neon navigation signs, workstation monitors, server racks, cables, hanging lamps, floor signage, and interactive camera movement.

The content drawer preserves the portfolio's project, experience, stack, education, honors, and contact information while keeping it out of the 3D scene so decorative objects never obscure readable text.
