NorthStar

A control plane for Linux hosts where command delivery is a state machine, not a fire-and-forget POST. Register a host, emit telemetry, queue work, lease it to an agent, then acknowledge it with the active lease token.

This is a public state-machine mirror, not an exposed production control plane. The repository contains the Spring controller, PostgreSQL repository, signed agent requests, integration tests, and local observability stack.
