The public page intentionally does not expose an unauthenticated Java/PostgreSQL control plane. It exercises the same documented transitions in-browser; the real controller, persistence layer, auth, integration tests, Docker Compose stack, Prometheus, Grafana, and OTLP wiring remain inspectable in the repository.
Java API controller ↗Host registration, auth-gated heartbeat/telemetry, online status, idempotent command queueing, leasing, acknowledgement, and audit. PostgreSQL repository ↗Transactional persistence for hosts, telemetry, command lifecycle, lease ownership, and audit events. API integration tests ↗Executable evidence for the public control-plane contract rather than a screenshot-only demo. C++ host agent ↗Registration, telemetry delivery, HMAC-signed requests, retry/backoff, and local spooling. Local deployment ↗Control plane + PostgreSQL + Prometheus + Grafana + OpenTelemetry collector.
