Could it happen again?

Seeded faults keep the reproduction schedule controlled. Replay equivalence compares supported events under the same constraints rather than promising deterministic behavior for an entire production network.

What is actually running?

The fault and replay logic run as compiled Go in the browser. The adapter substitutes for local TCP sockets; this is a real core demo with a browser transport boundary.

Inspect browser adapter
The browser adapter replaces local TCP sockets only; fault decisions, graph construction, event types, signatures, and replay equivalence come from Kestrel's Go packages.Repository
